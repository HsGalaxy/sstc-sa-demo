feat: STC Platform - full stack implementation of the S01-S04 architecture

Reference implementation of the "Smart Working Management App (small teams)"
case study: the C4 design of the report mapped onto a runnable system.

Backend (Java 8, Spring Boot 2.7.18, Spring Data JPA, H2)
- S01 identity, role and access: accounts, role matrix, permission policy
  overrides, session tokens, effective permission lookup and an access audit
  of every protected call
- S02 task dashboard: Kanban tasks with operation logging, delivery cycles,
  file tracker with multi condition query, version history and rollback, OKR
  and key results, live indicators, bottleneck detection, weighted performance
  score with A/B/C/D grading
- S03 team collaboration: channels, group chat with @mention detection and
  targeted notifications, meeting lifecycle with simulated transcription and
  an AI summary, notification inbox and a ranked smart digest
- S04 toolbox: document editing with an Office API quota check, slide decks,
  Git repositories with commit history and publishing, containerised dev
  environments with start/stop/status/heartbeat, project file upload with
  validation and share links with expiry and revocation
- Cross cutting: audit service, session based auth filter, uniform error
  contract, OpenAPI documentation, idempotent demo seeder

Frontend (React 18 + TypeScript + Vite, no UI framework)
- 17 screens across the four sub-systems: drag and drop Kanban, chat with
  mention highlighting, meeting transcript and AI summary viewer, toolbox
  panels, identity administration and access audit
- Typed API client as the single source of truth for the contract
- Production bundle built straight into the backend static resources so one
  jar serves the API and the dashboard

Docs and tooling
- README, docs/ARCHITECTURE.md (C4 to code map, story to endpoint to table),
  docs/API.md (complete REST reference), docs/DEMO_SCRIPT.md (ten minute
  walkthrough), 17 captured screenshots
- scripts/smoke-test.ps1: 36 end to end checks including the negative cases
- scripts/capture-screenshots.mjs: headless Chrome capture through the
  DevTools protocol
